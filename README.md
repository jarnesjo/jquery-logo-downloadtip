# jQuery Logo Downloadtip

### Example
http://demo.jarnesjo.net/jquery-logo-downloadtip/

## Description
Simple plugin to allow users to download multiple logotype image types when they try to grab low resolution logo.
Initiative after seeing http://relogo.org/

#### Disclaimer
Tip-css structure from Twitter Bootstrap (http://twitter.github.com/bootstrap/)
